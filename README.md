# ColorStack UPRM Official Website

Official website for the ColorStack chapter at the University of Puerto Rico,
Mayagüez. Built and maintained by StackWorks.

## Purpose
- Introduce the chapter to students, faculty and sponsors
- Give prospective members a clear path to join
- Showcase our events, team and sponsors

## Stack
- FrameWork: React
- Build tool: Vite
- Language: TypeScript
- Styling: Tailwind CSS
- Hosting: Cloudflare Pages

## Structure

```
public/            static assets served as-is
src/
  assets/          images, icons, fonts
  components/      reusable UI components
  pages/           top-level page components
  styles/          global styles and Tailwind config
```

## Getting Started
```bash
npm install
npm run dev
```

## Contributing
1. Create a branch off `main`: `git checkout -b feat/short-description`
2. Commit your work and push the branch
3. Open pull request into `main`
4. Lead will review and merge | NOBODY pushes to `main` directly

Branch naming: `feat/`, `fix/`, `chore/`, `docs/`
